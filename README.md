# AEDIA · Material del equipo de cierre

Web interna del equipo de cierre para trabajar la cuenta de AEDIA. Uso interno y confidencial.

## Páginas
- `index.html`: portada
- `briefing-aedia.html`: briefing ejecutivo
- `informe-operativo-aedia.html`: informe operativo
- `guia-llamada-aedia.html`: guía de llamada interactiva
- `temarios-aedia.html`: los 20 temarios íntegros, con filtros y la encomienda FUNDAE
- `playbook-aedia.html`: playbook y script de AEDIA
- `onboarding-closers-aedia.html`: actas de las sesiones de onboarding con AEDIA
- `vocabulario-aedia.html`: vocabulario técnico de las formaciones
- `plan-cierre-aedia.html`: plan de cierre (rescate, RR. HH., multi-matrícula, cierre de año, 30 días, role plays)

## Publicar en GitHub Pages
1. Sube todos los archivos de esta carpeta a la raíz del repositorio (incluido `.nojekyll`).
2. En **Settings → Pages**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. La web queda en `https://<usuario>.github.io/<repositorio>/`.

La web no se indexa en buscadores (`robots.txt` y `noindex`), pero cualquiera con el enlace puede abrirla.
